What you just saw

      

        Everything inside the terminal above is the actual output of the
        SessionStart hook — what claude-daily prints every time
        you start a new Claude Code session. The data shown is a sample;
        your dashboard renders from your own ~/.claude/projects/*.jsonl history.
      

    


    

      
How it works

      
    
        
  1. 1Daily aggregation. Reads ~/.claude/projects/*.jsonl, computes tool/permission/prompt metrics, writes metrics-store.json. Cached gate: at most once per day.
    2. 
        
  2. 2Hybrid prompt classifier. Lexical cues classify ~98% of reactions; a zero-shot NLI head (DeBERTa) is the fallback. 50-pair eval.
    3. 
        
  3. 3Weekly LLM tagging. A detached claude -p worker labels recent sessions with free-form topics — runs once a week, doesn't block the dashboard.
    4. 
        
  4. 4Scout. When metrics drop, a separate background worker searches the web and GitHub for actionable tips and surfaces them in the SCOUT FINDINGS block.
    5. 
      

    


    

      
Install

      
Inside Claude Code:

      
$ /plugin marketplace add gyanesh-m/claude-daily
$ /plugin install claude-daily@claude-daily
$ /reload-plugins

      
Or standalone:

      
$ git clone https://github.com/gyanesh-m/claude-daily.git
$ cd claude-daily && ./install.sh
